# CUHK-X Small Model Track

Мультимодальное распознавание 40 бытовых действий без RGB. Модель ≤ 100 МБ,
без больших предобученных бэкбонов, обучение с нуля.

**Дедлайн Kaggle: 15 сентября 2026.** Цель: Excellence (private LB top 15%).
Прочитать перед работой, в этом порядке:
0. [docs/HANDOFF.md](docs/HANDOFF.md) — **входная точка**, если ты здесь впервые
   (или это новая сессия / другой агент). Полный ввод в курс за 5 минут:
   состояние, блокеры, принятые решения и почему их не надо переигрывать.
1. [docs/findings.md](docs/findings.md) — накопленная разведка, гипотезы, разбор
   публичных решений.
2. [docs/eda.md](docs/eda.md) — **обязательный этап**, а не разминка. См. ниже.

> ## ⛔ EDA — гейт, а не формальность
>
> **Пока не пройден блок 1 из [docs/eda.md](docs/eda.md), модели не пишутся.**
>
> На этом соревновании EDA и есть основной рычаг. Масштаб отобран правилами
> (нет претрейна, кэп 100 МБ), а тюнинг архитектуры внутри ветки нечем измерить
> — публичный LB это 201 клип, один клип = 0.5%. Отдача лежит в том, что ты
> узнаёшь про данные: какие модальности реально присутствуют, как выровнены
> разные частоты, что кодирует `<trial>`, какая палитра у Depth_Color, есть ли
> артефакты вроде «длина клипа предсказывает класс».
>
> Лучшее публичное решение получило 0.716 на двух модальностях из шести ровно
> потому, что этих вопросов никто не задал.
>
> Каждое число в EDA обязано быть вычислено из файлов. Хардкод-список, идущий
> в `plot()`, — запрещённая конструкция (см. анти-паттерн в `docs/eda.md`).

## Старт с нуля на новой машине

```bash
python -m venv .venv && source .venv/Scripts/activate   # Windows: .venv\Scripts\activate
pip install -r requirements.txt
huggingface-cli login          # датасет gated: сначала принять условия на HF
```

### Шаг 1 — опись архива за 1.67 ГБ (сделать первым)

```bash
python code/data/download.py probe
python code/data/inventory.py data/raw/HAR.zip --json data/meta/inventory.json
```

Качает только последний том split-архива и читает из него центральный каталог,
где перечислены **все** файлы всех 44.6 ГБ. Отвечает разом на два вопроса:

1. Какие модальности есть и сколько весит каждая → план выборочной распаковки.
2. **Есть ли в тренировочном архиве пользователи 10, 11, 25, 26.** Сайт объявил
   их тестовыми, но пример в карточке HF показывает `user10` внутри трейна.
   Если они там есть — это объясняет кластер 0.98 на лидерборде и меняет
   стратегию целиком. Скрипт печатает вывод явно.

### Шаг 2 — тест, 2.79 ГБ

```bash
python code/data/download.py test
python code/data/index.py --test        # TODO: матрица доступности модальностей
```

«Not every clip has every modality» — нужна матрица `clip × modality` до того,
как проектировать фьюжн.

### Шаг 3 — остальные 43 ГБ в фоне

```bash
python code/data/download.py train
zip -s 0 data/raw/HAR.zip --out data/raw/HAR_full.zip   # или 7-Zip по HAR.zip
python code/data/extract.py Skeleton IMU                # сначала лёгкие
```

Модальность — верхний уровень иерархии, распаковывается по одной. Пик по диску:
44.6 ГБ архива + то, что распаковал. Тяжёлые Depth/IR/Thermal — только когда
дойдут руки.

## Структура

```
code/
  data/        download.py  inventory.py  extract.py   ✔ готовы
               index.py     — индекс клипов + матрица доступности модальностей
               align.py     — выравнивание разных частот по таймстемпам в именах

                              раскраску глубины), crop.py (bbox из скелета /
                              вычитание фона), skeleton.py, imu.py, radar.py
  datasets/    multimodal.py — modality dropout, отсутствующие ветки
  models/
    branches/  video_tsm.py, skeleton_gcn.py, imu_tcn.py, radar.py
    fusion.py  — взвешенный late fusion + перенормировка по присутствующим
  train/       loop.py, cv.py (GroupKFold по user), augment.py
  eval/        metrics.py, tta.py, calibrate.py (коррекция приора)
  submit/      make_submission.py   ← вызывается из inference.sh

configs/       default.yaml — все подтверждённые константы
data/          raw/ extracted/ cache/ meta/    (в .gitignore, десятки ГБ)
checkpoints/   model.pth — то, что уходит в сабмит-пакет
experiments/   логи и артефакты прогонов
notebooks/reference/  — два публичных ноутбука + их разбор в _analysis/
docs/          HANDOFF.md  — входная точка для новой сессии / другого агента
               findings.md — разведка, гипотезы, решения
               models.md   — кандидаты по модальностям, fusion, бюджет параметров
               eda.md      — обязательный чеклист EDA (гейт перед моделями)
```

Дерево повторяет требуемый пакет Stage 2 (`code/`, `checkpoints/model.pth`,
`inference.sh`, `README.md`), чтобы при попадании в топ-15 ничего не
переделывать.

## Порядок работ

**Этап A — EDA (гейт).** Полный чеклист в [docs/eda.md](docs/eda.md).

1. Блок 0 — опись архива за 1.67 ГБ. Развилка по пользователям 10/11/25/26,
   размеры модальностей, расшифровка `<trial>` (помещение?).
2. Блок 1 — тест за 2.79 ГБ. Матрица доступности `clip × modality`,
   проверка `test.csv` на упорядоченность, тривиальный классификатор на одних
   метаданных (длина клипа + набор модальностей) как тест на артефакты.
3. Блок 2 — реальность каждой модальности по мере распаковки: палитра
   Depth_Color, формат скелета, частота IMU, формат радара, битые кадры.

Артефакты на выходе: `data/meta/{inventory.json, clips_train.csv, clips_test.csv,
availability.csv}` и `notebooks/01_eda.ipynb`. Гипотезы в `findings.md` —
подтверждены или закрыты.

**Этап B — валидация.** `GroupKFold` по `user`, 4–5 фолдов, разбиение
зафиксировано навсегда. Это главный прибор: он на порядок точнее лидерборда.
Автор публичного 0.716 получил subject-CV [0.7156, 0.7187] при LB 0.716 —
отложенные субъекты предсказывают LB честно. Если `<trial>` кодирует помещение,
добавить leave-one-environment-out как отдельный диагностический прогон.

**Этап C — модели.**

4. MiniRocket на IMU за вечер — калибровка сложности (разведка, не в сабмит).
5. Скелет: ST-GCN → CTR-GCN, 4 потока (joint / bone / motion). Основная ставка:
   правилам соответствует, с нуля, 1.4M параметров.
6. Depth/IR: ResNet-18 + TSM с нуля, кроп из скелета, обращённый colormap.
7. Thermal тем же пайплайном — сильнейшая одиночная модальность по бейзлайну.
8. Late fusion + modality dropout + коррекция приора.
9. mmWave — только если останется время.

Цель — **0.75+ на своей cross-subject валидации**. Публичный потолок 0.716.
